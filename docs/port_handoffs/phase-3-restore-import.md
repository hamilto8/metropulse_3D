Behavior implemented: Whole-document validation still precedes all mutation. Static restore prepares every participant, detects duplicate ownership, applies in order, rolls back in reverse, and publishes descriptors only on success. Browser export reads current or recovery explicitly and downloads only validated plain JSON. Native import strictly decodes bytes, previews saved state/city/mission/control, refuses unconfirmed requests, backs up exact original bytes, migrates and revalidates, then commits current. Invalid/unconfirmed imports do not write backup or slots; interrupted publication leaves current/recovery unchanged even though a diagnostic backup may remain.
